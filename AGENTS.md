# Sugun Games — Tenet workspace

A browser arcade with Echo Shift, Pocket Snake, Brick Garage and Formula Club. The static index.html game picker links to each game's HTML entry. Use HTML, CSS, ES-module JavaScript, Canvas, and Node's built-in test runner. Formula Club uses the pinned PeerJS browser library and its shared signaling/relay service for host-authoritative 2–4 player rooms. No framework, bundler or private application server is required. Do not copy film/game assets or employer content. Work only in this repository; never access parent CV/credential files. Keep motion optional, keyboard and touch controls visible, and gameplay state independently testable. Small working code, deterministic rules and solvable levels are more important than extra mechanics.

Deployment target: static Vercel, with the existing GitHub Pages mirror. Public source and deployment are authorised by the user. No paid infrastructure or private data. Stage explicit paths and preserve other projects.
