# Echo Shift — Tenet workspace

An original, browser-native time-echo puzzle game for a personal portfolio. Use HTML, CSS, ES-module JavaScript, Canvas, and Node's built-in test runner. No framework, bundler or runtime service is required. Do not copy film/game assets or employer content. Work only in this repository; never access parent CV/credential files. Keep motion optional, keyboard and touch controls visible, and gameplay state independently testable. Small working code, deterministic rules and solvable levels are more important than extra mechanics.

Deployment target: static GitHub Pages. Public source and deployment are authorised by the user. No paid infrastructure or private data. Stage explicit paths and preserve other projects.
