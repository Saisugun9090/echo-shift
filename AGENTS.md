# Sugun Games — Tenet workspace

A seven-game browser arcade with Pocket Bowl, Bumper Bash, Doodle Classic with Relay mode, Echo Shift, Pocket Snake, Brick Garage and Formula Club. The static index.html game picker links to each game's HTML entry. Use HTML, CSS, ES-module JavaScript, Canvas, and Node's built-in test runner. Pocket Bowl, Formula Club, Bumper Bash and both Doodle modes use the pinned PeerJS browser library and its shared signaling/relay service for host-authoritative 2–6 player rooms. Pocket Bowl is turn-based ten-pin bowling with ten frames and solo practice. Doodle Classic is the default: one artist draws live, 1–5 others guess, each unique correct guess counts once, and the word is revealed only when the drawing timer ends. Classic keeps answers in per-player views, uses absolute deadlines, and rotates through one turn per player. Relay remains at doodle-relay.html and sends each player only their assigned task until the reveal. No framework, bundler or private application server is required. Do not copy film/game assets or employer content. Work only in this repository; never access parent CV/credential files. Keep motion optional, keyboard and touch controls visible, and gameplay state independently testable. Small working code, deterministic rules and solvable levels are more important than extra mechanics.

Deployment target: static Vercel, with the existing GitHub Pages mirror. Public source and deployment are authorised by the user. No paid infrastructure or private data. Stage explicit paths and preserve other projects.
